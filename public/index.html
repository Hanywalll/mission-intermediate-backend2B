Daftar Endpoint Referensi Mission 2B

  • GET /movies : Mengambil semua data film (SELECT *)
  • GET /movie/:id : Mengambil 1 film berdasarkan ID (SELECT by Id)
  • GET /movies/attribute/:attr/:val : Filter berdasarkan atribut lain
  • POST /movie : Menambahkan film baru (INSERT)
  • PATCH /movie/:id : Mengubah data film berdasarkan ID (UPDATE)
  • DELETE /movie/:id : Menghapus data film berdasarkan ID (DELETE)
